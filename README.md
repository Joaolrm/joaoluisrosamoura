# Portfólio - João Luís Rosa Moura

Portfólio pessoal desenvolvido para exibição no GitHub Pages.

## 🚀 Como publicar no GitHub Pages

1. Faça commit de todos os arquivos:
```bash
git add .
git commit -m "Adiciona portfólio"
git push origin main
```

2. No GitHub, vá em **Settings** > **Pages**

3. Em **Source**, selecione a branch **main** e a pasta **/ (root)**

4. Clique em **Save**

5. Aguarde alguns minutos e seu portfólio estará disponível em:
   `https://[seu-usuario].github.io/joaoluisrosamoura/`
